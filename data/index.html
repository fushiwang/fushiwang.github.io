Data & code

State alcohol consumption, 1994–2023

I compiled 1,530 state-year observations from NIAAA’s Table 4 to track alcohol consumption across the 50 states and Washington, D.C. The CSV reports gallons of ethanol per person for beer, wine, spirits, and all beverages combined. To reproduce my plot of annual state averages, save both files in one folder and run Rscript alcohol-trends.R there.

County disaster vulnerability and recovery

I matched county storm records from 2000–2005 with baseline social vulnerability and unemployment through 2010 to study how counties recovered. I’ve shared eight CSV files, including the merged panels, along with 14 R scripts for cleaning, exploring, and modeling the data. I included my saved recovery tables because the unemployment script depends on objects from an earlier R session. In a fresh session, its standardized storm magnitude is missing. I give the details in the README.

Cannabis policy and alcohol consumption

For our cannabis policy paper, we cleaned the policy and alcohol consumption data, matched them by state and year, and estimated separate models for beer, wine, and spirits. I’ve shared the scripts and cleaned inputs we used for those estimates.

Other analysis files

I’ve collected the scripts for four analyses here. The first two reproduce the congressional posting regressions and the six-page PageRank example. To run the education and interest income regressions, you’ll need an IPUMS-CPS extract for the Stata do-file. For the bike demand analysis, I’ve included the input data with the R Markdown notebook.
