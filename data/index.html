Data & code

State alcohol consumption, 1994–2023

Annual apparent consumption of beer, wine, spirits, and all beverages in 50 states and Washington, D.C., measured in gallons of ethanol per capita. The extract contains 1,530 state-year observations from NIAAA’s Table 4. To plot annual state averages, save the CSV and R script together and run Rscript alcohol-trends.R in that folder.

County disaster vulnerability and recovery

Eight CSV datasets from the authors’ saved analysis include county storm measures for 2000–2005, baseline social vulnerability, unemployment through 2010, and the merged recovery panels. The separate code download contains 14 R scripts covering data preparation, exploration, and modeling. The archive includes the authors’ saved recovery tables. Its README documents the original unemployment script’s dependence on prior session state and a missing standardized magnitude in a fresh run.

Other analysis files

Code for the congressional posting regressions, the PageRank example, the education and investment regressions, and the bike demand analysis. The Stata do-file requires a separate IPUMS-CPS extract. The bike archive includes its input data and R Markdown notebook.
